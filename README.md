# Introducción 
## Objetivos de la investigación

Este informe presenta un análisis de mercado de aplicaciones nutricionales existentes, diseño de encuesta para usuarios potenciales, y una guía práctica para recoger y analizar datos. El objetivo es identificar funcionalidades valoradas, problemas comunes, y oportunidades para desarrollar una nueva aplicación nutricional competitiva.

1. Analizar tres aplicaciones nutricionales líderes y comparar sus funcionalidades, modelos de negocio y UX.
2. Diseñar una encuesta (mínimo 15 preguntas) para recoger datos de usuarios potenciales.
3. Proponer recomendaciones y oportunidades para el desarrollo de la futura app.

## Metodología utilizada
1. Revisión documental y análisis de fuentes oficiales y reseñas actualizadas (sitios web oficiales, tiendas de apps, artículos especializados).
2. Diseño de encuesta con preguntas cerradas y abiertas; se recomienda aplicar la encuesta a al menos 15 personas por integrante del equipo.
3. Análisis cuantitativo y cualitativo de resultados (gráficos, tablas, resumen de hallazgos).

# Análisis de Aplicaciones Existentes (Resumen)
## Aplicaciones analizadas:
MyFitnessPal, FatSecret, Cronometer, YAZIO, Lose It!
## MyFitnessPal
###### Funcionalidades principales: 
Registro de alimentos, base de datos muy amplia (miles/millones de entradas), seguimiento de macros y ejercicios, barcode scanner, integración con wearables.
###### Experiencia de usuario:
Interfaz conocida y amplia adopción; curva de aprendizaje baja pero algunas secciones pueden resultar saturadas por publicidad en versión gratis.
###### Modelo de negocio:
Freemium: versión gratuita con funciones básicas y suscripción premium para funcionalidades avanzadas.
###### Puntos fuertes:
Base de datos extensa, ecosistema (integraciones), reconocimiento de marca.
###### Puntos débiles:
Publicidad en la versión gratuita, preocupación por precisión en algunos items comunitarios, ciertas funciones detrás de paywall.
###### Características innovadoras: Meal Scan (registro por foto) y amplias integraciones con terceros.
###### Fuente principal: MyFitnessPal (sitio oficial y análisis): MyFitnessPal mantiene una base de datos masiva y un modelo freemium. (Fuente: MyFitnessPal / BusinessOfApps).
## FatSecret
###### Funcionalidades principales: 
Registro de alimentos, base de datos, seguimiento de peso, escaneo de códigos de barras, comunidad y foros.
###### Experiencia de usuario:
Interfaz sencilla, enfocada en la funcionalidad principal; experiencia clara y directa.
###### Modelo de negocio:
Core gratuito; opción Premium con planes de dieta, herramientas avanzadas y sin anuncios.
###### Puntos fuertes: 
Gratuito y accesible; buena comunidad; facilidad de uso.
###### Puntos débiles: 
Menos integraciones con wearables comparado con competidores, menos enfoque en micronutrientes.
###### Características innovadoras:
Enfoque comunitario y reports gratuitos para usuarios básicos.
###### Fuente principal: 
FatSecret (sitio oficial y App Store): FatSecret ofrece funcionalidades básicas gratuitas y un Premium opcional. (Fuente: FatSecret).
## Cronometer
###### Funcionalidades principales: 
Seguimiento de calorías, macronutrientes y micronutrientes (hasta 80+ nutrientes), base de datos verificada, escaneo de código de barras, integración con dispositivos.
###### Experiencia de usuario:
Diseño orientado a datos nutricionales: más técnico, ideal para usuarios que necesitan precisión.
###### Modelo de negocio: 
Versión gratuita completa; Cronometer Gold (suscripción) añade análisis avanzados, historial ilimitado y experiencia sin anuncios.
###### Puntos fuertes:
Precisión y profundidad en micronutrientes; datos verificados; buenas integraciones.
###### Puntos débiles: 
Interfaz menos amigable para usuarios casuales; curva de aprendizaje mayor.
###### Características innovadoras:
Enfoque en micronutrientes y datos de laboratorio, adecuado para profesionales y usuarios exigentes.
###### Fuente principal:
Cronometer (sitio oficial): Cronometer destaca por su enfoque en micronutrientes y datos verificados. (Fuente: Cronometer).
## YAZIO
###### Funcionalidades principales:
Registro de alimentos, planes de pérdida de peso, seguimiento de ayuno intermitente, recetas y base de datos, escáner de códigos.
###### Experiencia de usuario:
Interfaz limpia y moderna; experiencia guiada con planes y recomendaciones.
###### Modelo de negocio: 
Modelo freemium: funciones básicas gratuitas; YAZIO PRO con características avanzadas (estadísticas extendidas, planes, listas de compras).
###### Puntos fuertes:
Buenas guías y planes, experiencia de usuario cuidada.
###### Puntos débiles:
Algunas funciones útiles (recetas, estadísticas) están reservadas para PRO.
###### Características innovadoras:
Integración de ayunos, mood tracker, y herramientas de planificación.
###### Fuente principal: 
YAZIO (sitio oficial y factsheet): YAZIO ofrece planes guiados y funciones PRO para usuarios avanzados. (Fuente: YAZIO).
## Lose It!
###### Funcionalidades principales:
Registro de alimentos, objetivos de calorías, escaneo de códigos de barras, retos y comunidad.
###### Experiencia de usuario:
Interfaz amigable y enfocada en perder peso; experiencia accesible para nuevos usuarios.
###### Modelo de negocio:
Freemium con opciones de suscripción para funciones avanzadas y planes personalizados.
###### Puntos fuertes: 
Fuerte crecimiento orgánico, buen onboarding y retención; gran base de usuarios.
###### Puntos débiles:
Algunas funcionalidades avanzadas requieren suscripción; competencia fuerte en el mercado.
###### Características innovadoras: 
Estrategias de adquisición orgánica y buen ASO; enfoque en gamificación y retos.
###### Fuente principal:
Lose It! (análisis y artículos): Lose It! creció a decenas de millones de usuarios con un modelo freemium y enfoque en retención. (Fuente: RevenueCat / Lose It!).

# Conclusiones y Recomendaciones
## Recomendaciones principales:
- Construir una experiencia minimalista para el registro diario, con opciones avanzadas para usuarios técnicos.
- Implementar barcode scanner + reconocimiento por foto (con advertencia de precisión) para reducir fricción.
- Ofrecer análisis de micronutrientes como característica premium dirigida a usuarios con necesidades específicas.
- Priorizar privacidad: explicar uso de datos y ofrecer opciones de exportación/borrado.
- Probar modelos de monetización: suscripción mensual, plan anual, y compras in-app por coaching.
